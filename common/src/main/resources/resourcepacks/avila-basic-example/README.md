# Avila Basic Example Pack

This is an example datapack for NovoAtlas based on the Avila mountains.

This is a basic example that uses default settings to replace the Overworld dimension with a custom map. It will create a small mountain range with caves but no cave biomes. 

To use this pack, you can simply replace the [height map](data/avila-example/novoatlas/heightmap) and [biome maps](data/avila-example/novoatlas/biome_map) with your own images. The biome map should be 1/4 the size of the heightmap. For best results, the width and height of images should be some whole-number multiple of 16 (to align with chunk boundaries). However, this is not strictly necessary.
