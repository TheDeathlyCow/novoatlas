# Avila Cave Biome Example Pack

This is an example datapack for NovoAtlas based on the Avila mountains.

This is an example that demonstrates how to specify cave biomes. This datapack provides its example in a custom dimension, rather than the Overworld. You can teleport there with this command:

```mcfunction
execute in avila-cave-biome-example:avila run teleport @s ~ ~ ~
```

To use this pack, you can simply replace the [height map](data/avila-cave-biome-example/novoatlas/heightmap) and [biome maps](data/avila-cave-biome-example/novoatlas/biome_map) with your own images. Be sure that all of these images have the same dimensions! For best results, the width and height of images should be some whole-number multiple of 16 (to align with chunk boundaries). However, this is not strictly necessary
