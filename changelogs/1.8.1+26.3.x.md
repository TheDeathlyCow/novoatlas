# NovoAtlas 1.8.1 for Minecraft 26.3 

NovoAtlas is now available for 26.3! This update involved some significant changes to world generation, and while I am fairly confident that most things should still be working as before, I am initially releasing this update as a beta.

- Updated to Minecraft 26.3
- Improved world generation performance based on refactors introduced by 26.3
  - Especially for maps that use lanczos and bicubic interpolation, performance should improve significantly.
- Deprecated the `novoatlas:no_cave_entrances` density function, it now functions identically to `novoatlas:caves`
  - This density function never did much anyway, and as it did not guarantee that the final map did not truly have any cave entrances at all.  
- The `novoatlas:caves` and `novoatlas:no_caves` density functions are now automatically generated.
  - There may have been a change in behaviour for these functions between versions.
