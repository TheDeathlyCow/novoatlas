# NovoAtlas 1.9.0 for Minecraft 26.3

This update significantly improves the blend to random blending algorithm. You can find an example of what the new blending will look like here: https://github.com/TheDeathlyCow/novoatlas/pull/32

- Improved the blend to random terrain blending algorithm.
- The bounded biome generator now also uses a noise parameter to blend biomes in the transition area.
- Increased the transition range in the example data pack to 256 blocks.
- Note that this update contains breaking changes for elements in the `novoatlas-experimental` namespace. Usage of objects in this namespace should be avoided unless you know what are you doing!
