# NovoAtlas 1.8 for Minecraft 26.2

- Added a `center_offset` field to map info objects.
  - Specified as a list of 2 floats that are in units of the width and height of the map.
- Added image wrapping
- Added blend to random image generation
- Added a new example datapack for blend to random image generation
- Increased the transition range of the heightmap density function in image map generators to improve structure blending around blocks high above the surface
- Improved the example datapacks in general

## Image Wrapping

The infinite void at the edge of maps has been replaced with image wrapping. Users can now specify a `image_wrapping` field in the map info to configure how the wrapping is handled. The options are similar to OpenGL texture wrapping, with the following options:

- `clamp_to_edge` (default): Uses the same pixel value as the edge forever
- `repeat`: Repeats the map image like its being tiled
- `mirrored_repeat`: Works like repeat but the image is mirrored for each repeat

The old void behaviour has been removed. Please raise an issue on GitHub is this behaviour is something you desire and would like to see return.

## Blend to Random Generation

A new chunk generator type, biome source type, and density function type have been added to enable the use of vanilla random generation beyond the world border of the central map image. The new chunk generator works very similarly to the existing image map generator except that it applies the blend function to both the final density and the preliminary height map. This blending function is still experimental and may not look very good for extreme transitions, but its better than a flat wall. The biome source simply generates a random set of biomes outside the central map.

A new example data pack, `avila-blend-to-random-example`, has been provided as a template for how developers can apply these settings to a map.

Importantly, all of these features are currently experimental (as indicated by their `-experimental` namespace) and may be subject to change in the future.

## Example Datapack Improvements

A pass has been done over all four example datapacks to hopefully make them more sensible and easier to use, both on their own and together.

- The basic example pack now overrides the Overworld instead of defining its own dimension to provide a better template for developers to use
- Each of the other example packs are now in a unique namespace (this means all the packs can be loaded together and they will work)
- Updated the READMEs
- Default-enabled example packs are now controlled by the boolean system property `-Dnovoatlas.enable-example-packs=true`, rather than the dev/prod environment flag. This will enable/disable ALL the example packs by default.
- All the potential properties of map info objects are now defined with more sensible defaults
  - `starting_y` has been set to 6 since the beginning. I do not know why it was like this, but it is now the more sensible default of 0.
  - This includes optional fields, which are just set to their defaults. Most optional fields are only optional for backwards compatibility so they should have been defined anyway.
  - The horizontal scale config now includes an expanded compound definition so that developers can easily tweak the interpolation method.
