# NovoAtlas 1.7.4: Optimizations

- Added a new `novoatlas:biome_cell_color_map` biome source that allows for 1/4 scale biome maps, providing significant storage savings for biome maps in memory.
- Replaced `novoatlas:color_map` with `novoatlas:biome_cell_color_map` in the example datapacks and downscaled the biome maps.
- `novoatlas:color_map` is now deprecated, but it may still be useful for people using larger scale maps.
- Optimized storage of height maps to only store 16 bits per pixel instead of 32.
- Some other minor performance improvements


### Migrating biome source

It is very highly recommended to migrate dimensions to the new biome source, as it provides significant memory savings. The old biome source may still be useful for users with maps that are scaled up from smaller images, though.

For the `avila-basic-example` datapack, migrating the dimension looks something like this:

`data/avila-example-dimension/avila.json`
```diff
{
    "type": "minecraft:overworld",
    "generator": {
        "type": "novoatlas:image_map",
        "map_info": "avila-example:avila",
        "settings": "minecraft:overworld",
        "underground_density_function": "novoatlas:caves",
        "biome_source": {
-           "type": "novoatlas:color_map",
+           "type": "novoatlas:biome_cell_color_map",
            "map_info": "avila-example:avila",
            "default_biome": "minecraft:the_void"
        }
    }
}
```

After making this change, you should down-scale your biome map image by 4x in an image editor like Photoshop or GIMP.
